# Code of Conduct

Fitto contributors are expected to maintain a respectful, professional, and inclusive environment.

## Expected behavior

- Give specific, constructive feedback about code and decisions.
- Assume good intent while asking for evidence and clear reasoning.
- Respect privacy, especially around health, identity, and message data.
- Keep technical discussions focused on the work rather than the person.
- Accept review feedback and document disagreements calmly.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate exposure of private information, sexualized conduct, and repeated disruption are not accepted in repository discussions or collaboration spaces.

## Enforcement

Report conduct concerns privately to the repository maintainer through their GitHub profile. Maintainers may edit or remove content, close discussions, reject contributions, or restrict participation when necessary to protect the project and its contributors.
